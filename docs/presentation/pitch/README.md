Core explanation: A high reading could be real weather or a bad sensor. SkyGuard checks the station's past, unusual patterns, T/P/RH consistency and nearby stations. It combines evidence into an explained decision, or asks for review when evidence is weak. It preserves original readings. This is a working simulated prototype, not a field-validated deployment.
